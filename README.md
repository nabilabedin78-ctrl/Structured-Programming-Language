## 📚 Topics Covered

This repository covers the following foundational topics of the C programming language:

* 🔹 **If-else:** Learning conditional logic, nested statements, and decision-making programs.
* 🔹 **Loop:** Understanding iterative logic using `for`, `while`, and `do-while` loops.
* 🔹 **Function:** Breaking down large codes into reusable, user-defined functions.
* 🔹 **Recursion:** Solving repetitive logic blocks by calling functions within themselves.
* 🔹 **Array:** Storing and managing collections of data efficiently in memory.
* 🔹 **String:** Manipulating text, character arrays, and built-in string functions.
* 🔹 **Pointer:** Understanding memory addresses, pointers, and direct data handling.
* 🔹 **W3schools C Tutorial:** Extra practice assignments and exercises following standard documentation.

## 💻 How to Run the Codes Locally

If you want to download and run any code from this repository on your computer terminal, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nabilabedin78-ctrl/Structured-Programming-Language
   ```
2. **Go inside a specific folder (Example: Loop):**
   ```bash
   cd Loop
   ```
3. **Compile the C file using GCC:**
   ```bash
   gcc filename.c -o program
   ```
4. **Run the program executable:**
   * On Windows: `program.exe`
   * On Linux/macOS: `./program`
